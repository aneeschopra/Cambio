One-time setup needed

This page needs a free shared database so two different computers can see the same game. A page hosted on Vercel/GitHub Pages has nothing like that built in, so you'll connect a free Firebase Realtime Database — it takes about 5 minutes and costs nothing for a game like this.

  1. Go to console.firebase.google.com and click Add project (any name is fine; you can skip Google Analytics).
  2. In your new project, open Build → Realtime Database in the left menu, click Create Database, pick any region, and start in test mode.
  3. Still on the Realtime Database page, open the Rules tab and set it to: 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
    then click Publish. (This makes the room data public — fine for a casual game with a friend, since room codes are private and hard to guess.)
  4. Click the gear icon → Project settings, scroll to Your apps, click the </> (web) icon, register an app (nickname anything), and copy the firebaseConfig object it shows you.
  5. Open cambio.html in a text editor, find FIREBASE_CONFIG near the top of the <script> section, and paste your values in (apiKey, authDomain, databaseURL, projectId).
  6. Save, redeploy to Vercel, and reload this page — this screen will disappear once it's configured correctly.

Only one of you needs to do this setup and redeploy — your friend just uses the link you send them afterward.

Create a room, then send your room code (or the link that appears next) to the person you want to play with — they enter it to join.
